# Frontend TaskBoard

Frontend aplikacji został wykonany w HTML, CSS,
JavaScript oraz Bootstrap 5.

## Pliki

- `login.html` – logowanie i rejestracja użytkowników.
- `boards.html` – lista tablic i zarządzanie tablicami.
- `board.html` – widok zadań wybranej tablicy.
- `style.css` – wygląd i responsywność interfejsu.
- `js/login.js` – obsługa logowania i rejestracji.
- `js/boards.js` – obsługa tablic.
- `js/board.js` – obsługa zadań, filtrów i statusów.

Frontend komunikuje się z backendem za pomocą REST API
i funkcji `fetch`.

Aplikacja umożliwia zarządzanie tablicami i zadaniami,
filtrowanie oraz wyszukiwanie zadań.
